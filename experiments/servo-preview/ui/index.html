Điều hướng khi đã vào website

Menu Navigate của Windows luôn hiển thị ngay cả khi mở website ngoài. Nhấn Ctrl + L để trở về trang nhập địa chỉ, Alt + ← hoặc → để quay lại/tiến tới, và Ctrl + R để tải lại.

Đây chưa phải bản thay thế NovaBrowser hiện tại: runtime thử nghiệm chưa hỗ trợ nhiều Servo webview trong cùng một cửa sổ. Không đăng nhập tài khoản nhạy cảm trong bản thử nghiệm.
